# Tutorials

Five short lessons that take you from an empty project to an exported video.
Each one is written against the LibreCut editor as it is built, and every
button, field, and menu it mentions exists in the app.

| Lesson | What you will do | Roughly |
| --- | --- | --- |
| [1. Import your media](01-import-media.md) | Create a project, bring in video, audio, and images, understand proxies | 10 minutes |
| [2. Cut and edit](02-cut-and-edit.md) | Arrange clips on the timeline, trim, split, add transitions and effects | 20 minutes |
| [3. Mix the audio](03-audio.md) | Set levels, pan, equalize, compress, duck, and automate a soundtrack | 15 minutes |
| [4. Add titles and captions](04-titles-and-captions.md) | Style text, animate it, and import subtitles from `.srt` or `.vtt` | 15 minutes |
| [5. Export the video](05-export.md) | Choose a size, a quality, and an encoder, and render the file | 10 minutes |

## How these lessons are written

- Button and field names are in **bold**, exactly as they appear in the app.
  If a label is in quotation marks, it is the text you read on screen.
- Shortcuts are written as `Ctrl+Z`. On macOS, `Cmd` takes the place of `Ctrl`.
- Every lesson ends with a **Try this** exercise and a **Gotchas** section.
  The gotchas are the things that surprise people the most.

## Before you start

- You do not need an account, and nothing is uploaded. Media stays on your
  computer.
- The editor needs FFmpeg. Installers bundle it; if the first-run window says
  **FFmpeg was not found**, see
  [formats and platform requirements](../formats-and-platforms.md).
- If you want to check what a file is, or fix one the editor refused, the
  same reference page lists the supported formats and the recovery steps.
